# 门槛是否过高：逐级放宽的对照

- 日期：2026-11-02
- 问题：用户提出"是不是 G1 门槛太高了"
- 做法：
  - **不修改** `G1-criteria.md`，而是把门槛从严到松排成一个阶梯，最松的一档是"不亏钱"，看策略能过到哪一级。
  - 另外补跑了一组**对策略最有利、但仍算现实**的口径，脚本是 `research/analysis/bt01b_favorable.py`：
    - 滑点从每腿每次 0.10% 降到 0.03%；
    - 闲置资金放进 USDT 活期，按同期利率计息。
- 样本：只用样本内，没有解封
- 试验记录：`bt01b_favorable` 4 次，标注为"有利口径敏感性，不符合 G1 悲观口径"。到目前为止累计 50 次

## 结论

**问题不在门槛。在现实口径下，策略连"跑赢 USDT 活期"这一级都过不了。** 也就是说，做这个策略，不如什么都不做，把 USDT 放在同一家交易所的活期里。只有在"完美预知未来费率"这个不可能的前提下，策略才能跑赢活期；要达到 G0 底线，还得再加上"全部挂单成交"。

## 基准本身是否太苛刻

- **USDT 活期和策略承担同一家交易所的风险**，所以它是最公平的机会成本。换成美国短债，同期约 4%～5%，结论不变。
- **就算完全不设基准**，只看绝对收益，策略本身每年最多约 1.8%（有利口径）。连 G0 测算时假设的最低情形（5%）都达不到。
- 相比活期，策略多承担了逼空、单腿暴露、执行失误等风险，还要每年约 480 小时的投入。在这种情况下，风险补偿为 0 都过不了，说明问题不在于风险补偿取多少。
