## 2. 计算口径（悲观）

- **手续费**：一律按 taker 计算。OKX VIP0：现货 0.10%，永续 0.05%。
- **滑点**：取 R4 估计的 75 分位。R4 没有覆盖到的品种或时段，按每腿每次 0.10% 计。
- **资金费**：按每次结算的实际时间和费率计算，不假设固定间隔，归档里的缺口不插值。只有在结算时刻持仓才计入。
- **持仓期间下架**：按最后一个可得价格平仓，滑点按 2 倍计。
- **下架后重新上线**：两段上线期视为两个独立品种，不能跨断档持仓。
- **基差损益**：平仓时现货与永续的价差变化计入损益。回撤按逐小时盯市计算。
- **占用资本**：
  - 变体 A：现货名义 + 永续保证金 + 安全垫。永续杠杆不超过 R5 给出的品种上限。
  - 变体 B：按 OKX 当前抵押品折扣率计算保证金，另留安全垫。
- **成交额过滤**：成交额缺失（null）的时段视为不满足品种池条件。OI 用成交额代替，代替阈值在 R1 中标定。

## 3. 比较基准

**B = OKX USDT 活期理财的实际出借利率（`lendingRate`）在评估区间内的时间加权平均**，数据来自公开接口 `finance/savings/lending-rate-history`。样本内和封存段各自用同期的 B。

## 4. 通过条件（全部满足才通过）

| # | 条件 | 说明 |
|---|---|---|
| 1 | **样本内**按资本计的净年化 ≥ B + 5 个百分点 | 解封的前提。不满足就不解封，直接判定不通过 |
| 2 | **封存段**按资本计的净年化 ≥ B + 5 个百分点 | 核心条件。B + 5pp 一定高于 G0 门槛（B + 2.4pp） |
| 3 | 最大回撤（按资本，逐小时盯市）≤ 10% | 样本内和封存段分别满足 |
| 4 | 分体制没有长期亏损 | 用 BTC 过去 90 天涨跌幅划分体制：牛市 > +20%，熊市 < −20%，其余为震荡。要求每个体制内累计净收益 ≥ 0，并且样本内不存在任何一个滚动 180 天窗口的净收益低于资本的 −2% |
| 5 | 容量 ≥ 40,000 USD | 资金上限 2 万的 2 倍，按 plan.md 9.7 节方法计算 |
| 6 | 封存段至少完成 10 次完整的开平仓 | 交易太少无法判断，按不通过处理 |
| 7 | 如实报告试验次数 | 以 `research/trials.csv` 的统计为准，写进 G1 报告 |
| 8 | 独立复核 | G1 结论由一个不带前文的 agent 复核，复核意见附在报告里。复核发现口径错误时，修正后按同样的条件重新判定 |

## 5. 解封规则

- 只解封一次，而且要征得用户同意（`LAB_UNSEAL=1` + reason）。
- 解封后不得修改参数、规则、品种池或变体选择。封存段结果不通过就判定 G1 不通过，按 plan.md 19.1 节处理：停止该策略，不写执行代码。
- 封存段只用于最终判定，不用于调参或选择变体。
