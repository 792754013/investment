# OPP-007 日线趋势跟踪：快速否证方案

2026-11-04 写定，在看任何结果之前提交。

- 用户在 OPP-006 结论之后选择了这个方向。
- 这是快速否证阶段：先用样本内数据判断值不值得做。如果通过，再写 G1 条件文件，交用户确认。
- 封存段（2026-05-01 之后）不动。

## 1. 想回答的问题

加密货币在日线到周线上有趋势：涨的时候容易继续涨，跌的时候容易继续跌。按规则顺着趋势持有，跌破趋势就离场（或者反手做空），扣掉手续费、滑点和资金费之后，能不能比下面两个基准更好？

- 一直持有（买入不动）；
- 拿着现金。

和 OPP-006 的区别：

| | OPP-006 | OPP-007 |
|---|---|---|
| 每笔成本占一波幅度的比例 | 很大 | 很小（一次趋势动辄 20%～100%，成本约 0.2%） |
| 是否拼速度 | 是 | 不拼，每天收盘看一次 |

难点在于假突破反复止损，以及趋势跟踪本身回撤很大。

## 2. 数据

- **Binance 现货日线**（data.vision 公开归档，不需要 Key），2017-08 起，入库为 `bn_spot_1d`。
- **Binance U 本位永续资金费**，有数据的月份起，入库为 `bn_funding`。
- **品种**：
  - 主口径：BTC、ETH。
  - 辅助口径：2018 年初就在 Binance 有 USDT 交易对的大市值币，名单事先固定为 BTC、ETH、XRP、ADA、LTC、EOS、XLM、NEO、TRX、BNB。名单里包括后来大幅衰落的 EOS、NEO、XLM。这个名单仍可能有一些幸存者偏差（当年不在 Binance 的币没有收录），会如实注明。
- **切分**：
  - 2017-08～2022-12 是"建模段"，只用来看参数敏感性；
  - 2023-01～2026-04 是"检验段"，主策略事先固定，这一段只看一次。

主策略没有需要拟合的参数，所以检验段主要用来看"最近还有没有用"。

## 3. 策略（全部事先固定）

**信号**（每天 UTC 收盘计算，次日按收盘价成交；延迟敏感性改为晚 1 天成交）：

- **均线**：收盘价在 N 日均线上方记 +1，否则记 0（只做多）或 −1（多空）。N = 20、50、100、200。
- **动量**：过去 N 日收益为正记 +1，否则记 0 或 −1。N = 20、60、120、250。
- **通道突破**：创 N 日新高时做多，跌破 N/2 日新低时离场。N = 20、55、100。

**主策略（事先指定，不挑参数）**：

- 把 4 个均线信号和 4 个动量信号等权平均，作为"趋势强度"，范围是 0～1（只做多）或 −1～1（多空）。
- 每个品种按目标波动率定仓位：仓位 = 趋势强度 × 目标年化波动 ÷ 近 60 日实际年化波动。
- 目标年化波动 40%，单品种仓位上限 1 倍（不加杠杆）。
- 主口径 BTC、ETH 各占一半资金。

**变体**（全部报告，不从中挑最好的）：

- 只做多和多空两种；
- 单个信号的每一个 N；
- 目标波动 20%、40%、60%；
- 仓位上限 1、2、3 倍：用户关心杠杆，这里看加杠杆后的回撤。

**成本（悲观）**：

| 项目 | 取值 |
|---|---|
| 调仓手续费 | 每次调仓按成交额收 0.05%（吃单） |
| 滑点 | 0.05% |
| 小调仓 | 仓位变化小于 5% 不调，避免在模型里每天频繁小额调仓 |
| 做多的资金费 | 按 Binance 实际资金费支付；没有数据的月份按每 8 小时 0.01%（年化约 11%）支付 |
| 做空的资金费 | 没有数据的月份不收（悲观） |
| 现金收益 | 闲置资金不计利息（悲观） |

现货做多也可以不付资金费。这里一律按永续计，是悲观口径。

## 4. 停止条件（快速否证，看结果之前写定）

主策略（BTC + ETH，只做多，目标波动 40%，不加杠杆），出现下面任意一条就停止：

1. 全样本扣成本后的年化收益 ≤ 4%（大致相当于把 USDT 放活期的收益）。
2. 和一直持有 BTC/ETH 各半相比，夏普比率没有更高，而且最大回撤也没有至少缩小三分之一。也就是说，相对一直持有没有好处。
3. 按自然年算，正收益年份不到 60%。
4. 去掉收益最好的 1 年，年化收益 ≤ 0。
5. 检验段（2023-01～2026-04）扣成本后为负。
6. 年净额低于 3,000 元（G0）。按 30 万元本金计算，即年化扣成本后低于 1%。条件 1 已经比这一条更严。

**只做记录、不单独触发停止的观察**：

- 延迟 1 天后年化收益下降超过一半，说明结果脆弱，要在结论里写明；
- 多空版和辅助口径的结果；
- 加杠杆后的最大回撤和爆仓情况。

## 6. 事先说明的预判

公开研究里，加密货币的趋势跟踪在 2017～2021 年很好，最近几年变弱。主要风险有三个：

- 大部分收益来自 2017、2020～2021 两段牛市；
- 检验段（2023～2026）可能只是跟着大盘涨，相对一直持有并没有优势；
- 横盘年份反复假突破，产生的成本和亏损。

预判是：大概率能把回撤压到一直持有的一半左右，但年化收益不一定比一直持有高。
