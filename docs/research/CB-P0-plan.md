## 1. 吸取一期的教训

1. **先算清成本和机会成本，再看收益。**
   - 一期失败的直接原因是：往返成本 0.70%，而机会持续时间短。
   - 可转债的手续费低（佣金约万 0.5～万 2，没有印花税），持有期以周、月计，成本结构比一期友好得多。真正需要估准的是低价、小盘转债的**冲击成本**和**流动性**。
2. **基准要选同类风险的"什么都不做"**：
   - 主基准：**中证转债指数（000832）**，代表买入并持有全市场转债。
   - 辅助基准：**货币基金 / 国债逆回购**，代表无风险收益。
   - 策略要同时说明比它们各多赚多少。
3. **先做最便宜的否证。** P1 第一步先跑"双低轮动"这个公开的基准策略，加上悲观成本，看它能不能跑赢中证转债指数。如果连这一步都跑不赢，后面的下修博弈、强赎博弈就不值得做。
4. **体制依赖要提前查。** 转债市场有几次明显的体制切换：
   - 2018 年前市场很小；
   - 2021～2022 年估值偏高；
   - 2023 年底到 2024 年出现信用和退市冲击；
   - 2024 年起新发行明显减少。

   G1 要按年份和体制分别报告。

## 2. 机制（准入六问，草稿）

| 问题 | 回答（待研究验证） |
|---|---|
| 对手方是谁 | ① 不想还钱的发行人：在回售或到期压力下主动下修转股价；② 机构：受评级和风控限制，被迫卖出或回避低评级、低价、有退市风险的转债；③ 追涨的散户：为高价转债付出过高的溢价 |
| 机构为什么不来 | 单只规模小（多为 3 亿～10 亿），条款复杂，需要逐只研究；评级门槛使机构不能持有低评级券 |
| 容量 | 待 C6 估算。按 1 万～2 万级别的资金，单只日成交额通常足够，但低价券和临近退市的券例外 |
| 最坏情况 | 正股退市导致转债无法足额兑付（2023～2024 年已发生：蓝盾、搜特、鸿达、岭南、正邦等），单只可能亏损 70% 以上；监管规则突变 |
| 怎么消失 | 双低策略被广泛使用，导致溢价压缩；新发行减少，可选数量下降；下修规则收紧 |
| 我的成本优势 | 资金小，可以进出小盘券；自动化逐只解析条款，持续跟踪下修、强赎、回售公告 |

注意 plan.md 2.5 节第 1 条：双低轮动不是对冲策略，有方向暴露。它的结构性理由是"债底保护加转股期权"，下限保护是纯债价值，以及信用筛选。所以**信用和退市风险是第一风险**，R 系列研究必须包含已退市、已违约的转债。

## 3. 免费数据可行性（2026-11-02 实测，akshare 1.20.22）

| 需要的数据 | 免费来源 | 实测结果 | 时点正确性 |
|---|---|---|---|
| 全部转债清单，含已退市 | 东方财富 `bond_zh_cov` | ✅ 1,066 只，申购日期 2007-07 ～ 2026-10。已退市和违约的都在（如搜特、鸿达、岭南、正邦、蓝盾），退市后转入的 404xxx 退市板代码也在 | 清单本身没问题 |
| 转债日线（含已退市） | 新浪 `bond_zh_hs_cov_daily` | ✅ 蓝盾转债日线到 2023-07-28 退市，可以覆盖退市过程 | ✅ |
| 纯债价值、转股价值、溢价率日序列 | 东方财富 `bond_zh_cov_value_analysis` | ✅ 搜特转债从上市一直到 2023-08 | 纯债价值的算法是数据商口径，需要抽查 |
| 转股价历史（下修） | 用转股价值和正股价反推 | ✅ 搜特转债反推出 5.36 → 2.90（2020-09）→ 1.62（2021-08） | ⚠️ 只能得到**生效日**，得不到董事会提议和股东大会公告日。下修博弈需要公告日 |
| 正股日线（含已退市） | 东方财富 `stock_zh_a_hist` | ✅ 搜特股份到 2023-05 | ✅ |
| 发行条款（初始转股价、到期日、规模） | 巨潮 `bond_cov_issue_cninfo` | ✅ 可以按年份段批量拉取 | ✅ |
| 强赎、回售、下修条款原文和状态 | 集思录 `bond_cb_redeem_jsl` | ⚠️ 只有当前存续券。集思录的调整记录接口在未登录时返回空 | ❌ 没有历史 |
| 信用评级历史 | — | ❌ 清单里只有当前评级 | ❌ 评级历史需要从巨潮的跟踪评级公告中提取，或使用 Tushare |
| 公告（下修提议、强赎公告、回售公告） | 巨潮资讯公告检索 | 未测 | 公告有发布时间戳，可以做到时点正确，但需要按标题分类 |
| 基准：中证转债指数 | 指数日线接口 | 未测 | ✅ |

**结论**：
- **双低轮动基准回测，用免费数据就够了**：清单、日线、溢价率、正股、退市过程都有。
- **下修博弈和强赎博弈**需要时点正确的事件日期。免费路径是巨潮公告检索，加标题规则分类，再人工抽检。如果做不下来，再考虑 Tushare 积分（属于付费，按 plan.md 8.5.4 的精神，要先证明必要，并征得用户同意）。
- **评级历史是缺口**：
  - P1 先用"价格 / 纯债价值 / 正股市值 / 是否 ST"代替评级做信用筛选；
  - 报告里注明"当前评级有前视，不得用于回测筛选"。

## 5. P1：快速研究 → 可转债 G1

| 编号 | 问题 | 方法 |
|---|---|---|
| C1 | 双低轮动能否跑赢中证转债指数 | 每周或每月调仓、等权 N 只、悲观成本；按年份和体制拆开；**这是否证的第一关** |
| C2 | 信用与退市尾部 | 统计全部退市、违约转债的退出路径和损失；对比各种筛选规则（价格 < 某值、正股市值、ST）能挡掉多少 |
| C3 | 下修事件研究 | 先用生效日做粗略研究，再用公告日精确化：提议前后的超额收益、提议通过率、下修到底的比例 |
| C4 | 强赎事件研究 | 触发计数期间和公告后的价格收敛；"不强赎"公告的影响 |
| C5 | 回售博弈 | 进入回售期前的价格与下修概率 |
| C6 | 成本与容量 | 用日成交额估冲击成本，取悲观值；每只最大可持仓量 |

G1 门槛等 C1 的口径确定后，由用户确认并提交，**在规则回测之前**。草案方向：
- 样本内超额 ≥ 中证转债指数 + X pp；
- 同时 ≥ 货币基金 + Y pp；
- 最大回撤 ≤ Z；
- 每个体制不长期亏损；
- 信用事件期（2023-11 ～ 2024-06）的表现单独报告。
